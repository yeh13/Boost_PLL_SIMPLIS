## GUI next action

From the SIMetrix/SIMPLIS command shell, use the SIMPLIS menu's Run Netlist command and select point_00.net. This lets the normal GUI workflow perform preprocessing and launch.
Alternatively change the command-shell working directory to this folder and execute run_all_adc_only.sxscr; this uses the documented PreProcessNetlist + RunSIMPLIS commands. It will stop on missing waveform export rather than manufacture results.
Do not run native_adc_template_source.sxsch: it is only a copied 4-bit vendor schematic used to invoke the 12-bit model generator, and its original graphical pins do not match a 12-bit instance. native_adc_generated.net is likewise generator provenance, NOT the calibration circuit. Use point_XX.net for actual tests.

After a successful run inspect the first data transition: it should occur at 1.000050us; DR ready should occur at 1.000060us. These are requested times, NOT measured times. Inspect event timestamps, not a coarse interpolated plot. At subsequent conversions the same DC code need not toggle; measure the first nonzero conversion from IC=0 and DR events.

All seven points must match the supplied MATLAB expected integers before declaring provisional scaling PASS.
If near-half-LSB points fail, measure the transition using progressively finer DC bracketing with OFFSET kept at zero. Record the two Vin bounds and the corresponding actual codes. Only measured evidence can authorize selecting the second offset candidate; it has not been adopted here.
Even seven successful points establish the requested provisional check, not a proof of every code boundary, exact half-code tie, saturation, or 2s sine-source acquisition parity.
